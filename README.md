# DefectMap — Система отслеживания дефектов на карте

**DefectMap** — это полнофункциональное веб-приложение для управления и отслеживания дефектов оборудования
на интерактивной карте. Система позволяет визуализировать расположение дефектов, отслеживать их статус,
приоритеты. Проект разработан с использованием современных технологий и предназначен для использования
в промышленных предприятиях, коммунальных службах и других организациях, где важно эффективно управлять
состоянием оборудования.

## Основные возможности

- **Интерактивная карта** — визуализация оборудования и дефектов на географической карте
- **Управление оборудованием** — каталог оборудования с возможностью назначения статусов
- **Отслеживание дефектов** — регистрация, классификация и мониторинг дефектов в реальном времени
- **Отчёты и аналитика** — анализ состояния оборудования и статистика дефектов
- **Управление пользователями** — система ролей и прав доступа
- **Аутентификация** — безопасная авторизация с использованием JWT
- **WebSocket** — обновления в реальном времени через Redis
- **Экспорт данных** — генерация PDF отчётов

## Технологический стек

### Бэкенд
- **Python 3.10+** с **FastAPI** — высокопроизводительный REST API framework
- **SQLAlchemy** — ORM для работы с базой данных
- **Alembic** — управление миграциями БД
- **PostgreSQL 15** — основная база данных
- **Redis** — кэширование и обмен сообщениями в реальном времени
- **JWT (PyJWT)** — аутентификация
- **Bcrypt** — хеширование паролей
- **FastAPI-Users** — готовое решение для управления пользователями

### Фронтенд
- **Vue 3** — прогрессивный JavaScript фреймворк
- **Quasar Framework** — UI фреймворк на базе Vue
- **Pinia** — управление состоянием приложения
- **Vue Router** — маршрутизация
- **Axios** — HTTP клиент
- **Chart.js** — графики и диаграммы
- **jsPDF** — генерация PDF документов
- **Nginx** — веб-сервер для продакшена

### DevOps
- **Docker** — контейнеризация
- **Docker Compose** — оркестрация контейнеров
- **Alembic** — миграции БД

## Требования

- Docker и Docker Compose (рекомендуется)
- или Node.js 24+ (для разработки фронтенда)
- или Python 3.10+ (для разработки бэкенда)
- PostgreSQL 15+ (если не использовать Docker)
- Redis (если не использовать Docker)

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd DefectMap
   ```

2. **Создайте файл `.env` на основе `.env.example`:**
   ```bash
   cp .env.example .env
   ```
   
   Отредактируйте переменные окружения:
   ```env
   DB_USER=defectmap_user
   DB_PASSWORD=secure_password_123
   DB_NAME=defectmap_db
   ```

3. **Запустите приложение:**
   ```bash
   docker-compose up -d
   ```

4. **Проверьте статус контейнеров:**
   ```bash
   docker-compose ps
   ```

5. **Доступ к приложению:**
   - Фронтенд: http://localhost
   - API: http://localhost:8000
   - API документация (Swagger): http://localhost:8000/docs
   - Redis: localhost:6379
   - PostgreSQL: localhost:5432

```bash

alembic upgrade head
```
